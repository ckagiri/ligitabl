How this is graded

Your picks earn a result, like a team does. Call the winner right and it’s a Win, whatever the score. Call a draw and you get a Win if it finished level, a Draw if one side edged it by a single goal, and a Loss if the margin was two or more. Call the wrong winner and it’s a Loss every time — only draw picks get the one-goal reprieve.
